## Suave y legible

Maple Mono tiene esquinas redondeadas y una cursiva con trazo manuscrito que queda muy bien en comentarios y palabras clave. Mantiene una proporción 2:1 exacta con caracteres CJK, así que alinea bien texto en chino o japonés.

## Variantes

En la página de releases verás varias versiones del mismo diseño:

```
MapleMono          → sin ligaduras
MapleMono-NF       → con iconos Nerd Font (para terminal y prompts)
MapleMono-CN       → con glifos chinos
-unhinted / TTF / variable
```

Para el editor y la terminal, la variante **NF** es la más práctica: un solo tipo de letra para todo.

## Personalizar antes de descargar

En la web oficial (font.subf.dev) hay un configurador para activar o desactivar ligaduras y variantes de caracteres concretos y descargar una versión hecha a tu gusto.

## VS Code

```jsonc
// settings.json
{
  "editor.fontFamily": "'Maple Mono NF', monospace",
  "editor.fontLigatures": "'calt', 'cv01', 'ss01'",
  "terminal.integrated.fontFamily": "'Maple Mono NF'"
}
```
