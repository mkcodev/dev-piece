## El terminal que Windows merecía

Windows Terminal es el reemplazo moderno del cmd y PowerShell clásico: soporte de Unicode y emoji, colores de 24 bits, múltiples pestañas y paneles, perfiles configurables, y una experiencia comparable a iTerm2 o Alacritty.

## Instalación

```powershell
winget install Microsoft.WindowsTerminal
# O ya viene preinstalado en Windows 11
```

## Acciones de inicio automático (startup)

En `settings.json`, añade `startupActions` para abrir una configuración específica al arrancar:

```json
{
    "startupActions": "new-tab -p PowerShell; split-pane -p \"Ubuntu (WSL2)\" -H"
}
```

Esto abre dos paneles al inicio: PowerShell arriba y WSL2 abajo.

## Tips para power users

- **Ctrl + Shift + P** abre la paleta de comandos (como en VS Code)
- **Ctrl + clic** en una URL la abre en el navegador
- **Arrastra y suelta** un archivo en la terminal para insertar su ruta
- Usa **perfiles de color diferentes** por contexto: rojo para servidores de producción, verde para desarrollo, azul para local

> **Perfil recomendado:** Configura PowerShell 7 (no el Windows PowerShell clásico) como perfil por defecto. Instálalo con `winget install Microsoft.PowerShell` para tener la versión cross-platform con mejor rendimiento y más features.
