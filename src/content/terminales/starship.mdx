## ¿Qué es Starship?

Starship es un prompt cross-shell ultrarrápido escrito en Rust. Su filosofía es simple: funciona perfectamente sin configuración (zero-config) pero admite personalización completa cuando la necesitas. Es compatible con bash, zsh, fish, PowerShell, Nushell, elvish, tcsh y más.

A diferencia de Oh My Posh, Starship usa un único archivo TOML para todas las shells. La misma configuración produce el mismo prompt en cualquier sistema operativo y cualquier shell, lo que lo hace ideal para mantener dotfiles sincronizados.

## Inicialización por shell

Añade la línea correspondiente al archivo de configuración de tu shell:

```bash
# bash (~/.bashrc)
eval "$(starship init bash)"

# zsh (~/.zshrc)
eval "$(starship init zsh)"

# fish (~/.config/fish/config.fish)
starship init fish | source

# PowerShell ($PROFILE)
Invoke-Expression (&starship init powershell)

# Nushell (~/.config/nushell/config.nu)
# Primero ejecuta: starship init nu | save -f ~/.starship.nu
source ~/.starship.nu
```

## Pro Tips

**Configuración preset:** Starship incluye presets predefinidos. Puedes aplicar uno directamente:

```bash
starship preset nerd-font-symbols -o ~/.config/starship.toml
starship preset catppuccin-powerline -o ~/.config/starship.toml
```

**Variables de entorno:** Define `STARSHIP_CONFIG` para usar una ruta de configuración personalizada, útil para múltiples perfiles:

```bash
export STARSHIP_CONFIG=~/.config/starship-minimal.toml
```

**Cacheo:** Starship usa caché automático para módulos lentos como `git_status`. Si el prompt tarda, revisa qué módulos están activos con `starship explain`.
