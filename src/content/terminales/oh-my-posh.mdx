## ¿Qué es Oh My Posh?

Oh My Posh es un motor de temas para el prompt de la terminal que funciona con **cualquier shell**: PowerShell, bash, zsh, fish, CMD, Nushell y más. Creado por Jan De Dobbeleer, permite mostrar información contextual en el prompt: rama de git, versión de Node/Python/Go, estado del entorno virtual, batería, hora y mucho más, con iconos gracias a Nerd Fonts.

A diferencia de Starship (también cross-shell), Oh My Posh usa temas en formato JSON con una configuración más visual y detallada. Soporta segmentos con formas personalizadas (powerline, hexágonos, bloques redondeados) y animaciones.

## Requisito: Nerd Fonts

Oh My Posh requiere una fuente con iconos. La más recomendada:

```powershell
# Instalar fuente con Oh My Posh directamente
oh-my-posh font install meslo

# O descargar manualmente desde
# https://www.nerdfonts.com/font-downloads
# Recomendadas: JetBrainsMono, MesloLGS, CaskaydiaCove
```

Configura la fuente en tu terminal:
- **Windows Terminal**: Settings > Perfil > Apariencia > Tipo de fuente
- **Alacritty**: `font.normal.family = "JetBrainsMono Nerd Font"`
- **VS Code**: `"terminal.integrated.fontFamily": "JetBrainsMono Nerd Font"`

## Configuración en PowerShell

```powershell
# Abrir el perfil de PowerShell
notepad $PROFILE
# o con Neovim:
nvim $PROFILE
```

```powershell
# $PROFILE (Microsoft.PowerShell_profile.ps1)

# Inicializar Oh My Posh con un tema
oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\catppuccin_frappe.omp.json" | Invoke-Expression

# Alternativamente, con ruta absoluta a un tema personalizado
# oh-my-posh init pwsh --config "C:\Users\TuUsuario\.config\omp\mi-tema.json" | Invoke-Expression
```

## Configuración en bash/zsh

```bash
# ~/.bashrc o ~/.zshrc
eval "$(oh-my-posh init bash --config ~/.config/omp/catppuccin_frappe.omp.json)"
# zsh:
eval "$(oh-my-posh init zsh --config ~/.config/omp/catppuccin_frappe.omp.json)"
```

## Ver todos los temas disponibles

```powershell
# PowerShell: explorar temas interactivamente
Get-ChildItem "$env:POSH_THEMES_PATH" | Select-Object Name

# Previsualizar un tema específico
oh-my-posh print primary --config "$env:POSH_THEMES_PATH\tokyo.omp.json"

# Cambiar tema temporalmente en la sesión actual
oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\agnoster.omp.json" | Invoke-Expression
```

## Pro Tips

**Actualizar Oh My Posh:**
```powershell
winget upgrade JanDeDobbeleer.OhMyPosh
# o
oh-my-posh upgrade
```

**Caché de segmentos lentos:** Si el prompt tarda demasiado, puedes cachear segmentos costosos (como git) con `"cache": { "duration": 60000 }` dentro del segmento.

**Prompt transitorio:** Activa `"transient_prompt"` para que el prompt de comandos anteriores se simplifique, manteniendo el terminal limpio.
