## ¿Qué es Alacritty?

Alacritty es un emulador de terminal de código abierto que utiliza la GPU para renderizar cada frame, lo que lo convierte en el terminal más rápido disponible en la actualidad. Está escrito completamente en Rust, lo que garantiza seguridad de memoria y un rendimiento excepcional sin sacrificar estabilidad.

A diferencia de terminales como iTerm2, Kitty o Windows Terminal, Alacritty tiene una filosofía minimalista: hace una sola cosa y la hace perfectamente. No incluye multiplexación de sesiones (para eso existe tmux o WezTerm), ni pestañas nativas, ni paneles. Es un lienzo en blanco, extremadamente rápido.

## ¿Por qué importa la aceleración por GPU?

Los terminales tradicionales renderizan texto usando la CPU, lo que se convierte en un cuello de botella cuando se trabaja con salidas largas, animaciones de prompt, o herramientas como `btop` que actualizan frecuentemente la pantalla. Alacritty delega todo el renderizado a la GPU mediante OpenGL, lo que resulta en:

- Latencia de input extremadamente baja (incluso en conexiones SSH lentas)
- Scrollback suave sin tearing
- Capacidad de manejar miles de líneas sin degradación de rendimiento

## Pro Tips

**Usar con tmux:** Alacritty no tiene pestañas nativas, pero combinado con tmux obtienes un setup profesional:

```bash
# Añade a tu ~/.zshrc o ~/.bashrc
alias t="tmux new-session -A -s main"
```

**Configuración modular:** Puedes separar el tema en un archivo aparte e importarlo:

```toml
# alacritty.toml
import = ["~/.config/alacritty/themes/catppuccin-frappe.toml"]
```

**Live reload:** Alacritty recarga la configuración automáticamente al guardar el archivo. No necesitas reiniciar el terminal para ver los cambios.

**Hints para URLs:** Alacritty incluye un sistema de hints que permite abrir URLs con el teclado sin usar el ratón. Presiona la tecla configurada y aparecerán letras sobre cada URL para seleccionarlas.
