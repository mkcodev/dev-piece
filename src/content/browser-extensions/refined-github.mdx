Refined GitHub es una extensión de navegador que añade más de 100 mejoras a la interfaz de GitHub. No cambia el diseño ni rompe nada: simplemente hace que las cosas que ya usas sean más rápidas, más claras y más intuitivas. Una vez que la tienes, notas su ausencia en cada máquina donde no está instalada.

## Top 10 features que añade

### 1. Opciones de merge en una línea
En lugar de tres botones separados, muestra un único botón de merge con un desplegable para elegir la estrategia (merge commit, squash, rebase). Recuerda tu última elección.

### 2. Linkificación de referencias
Los números de issue y PR (`#123`), SHAs de commits, y menciones de usuario en comentarios se convierten automáticamente en enlaces clicables, incluso cuando GitHub no los convierte.

### 3. Diff lado a lado en PRs
Añade un botón para cambiar entre la vista unificada (una columna) y la vista dividida (dos columnas) en cualquier diff de PR o commit.

### 4. Sticky header en PRs
La barra de navegación del PR (Conversation, Commits, Files changed) se queda pegada al tope mientras haces scroll. Deja de tener que subir hasta arriba para cambiar de sección.

### 5. Botón de copia en code blocks
Cada bloque de código en issues, PRs y README tiene un botón de copia directamente visible, sin necesidad de seleccionar el texto manualmente.

### 6. Filtros de notificaciones mejorados
La página de notificaciones permite filtrar por tipo (PR, issue, mention), repositorio y estado con un panel más potente que el de GitHub por defecto.

### 7. Previsualización de PR al hover
Al pasar el cursor sobre un enlace a un PR o issue, aparece un popup con el título, estado, autor y descripción sin necesidad de abrir la página.

### 8. Marcar archivos como vistos en masa
En la vista de Files Changed de un PR, añade un checkbox para marcar/desmarcar todos los archivos como vistos con un solo clic.

### 9. Reactions con contador visible siempre
Los contadores de reactions (👍, ❤️, 🚀) se muestran directamente en la lista de issues/PRs sin necesidad de abrir el hilo.

### 10. Barra de progreso en PRs
Muestra una barra de progreso visual en la lista de PRs indicando cuántos checks han pasado, cuántos están pendientes y cuántos han fallado.

## Cómo activar/desactivar features individuales

```
1. Haz clic en el icono de la extensión en la barra del navegador
2. Se abre la página de opciones de Refined GitHub
3. Cada feature tiene un toggle individual y una breve descripción
4. Los cambios se aplican al recargar la página
```

## Features a considerar desactivar

Algunas mejoras pueden interferir con flujos de trabajo específicos o con otras extensiones:

```
- "Hide useless newlines in diffs"   → puede ocultar cambios reales
- "Add keyboard shortcuts to merge"  → si usas otro sistema de shortcuts
- "Shorten URLs"                     → si copias URLs frecuentemente
```

## Compatibilidad

Refined GitHub funciona en Chrome, Firefox, Edge y Safari. Para GitHub Enterprise, necesitas especificar el dominio en las opciones de la extensión. La extensión es completamente open source y auditada públicamente en su repositorio de GitHub.
