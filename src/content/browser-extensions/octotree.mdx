## GitHub con navegación tipo IDE

Octotree añade una barra lateral a GitHub con el árbol de archivos del repositorio. En lugar de navegar carpeta por carpeta haciendo clic, ves toda la estructura del proyecto y saltas directamente al archivo que quieres.

## Instalación

- Chrome: [Chrome Web Store → Octotree](https://chromewebstore.google.com/detail/octotree-github-code-tree/bkhaagjahfmjljalopjnoealnfndnagc)
- Firefox: [Firefox Add-ons → Octotree](https://addons.mozilla.org/en-US/firefox/addon/octotree/)
- Edge: disponible en el Chrome Web Store

## Cómo funciona

Cuando visitas cualquier repositorio de GitHub, aparece un botón en el lateral izquierdo. Haz clic para abrir el panel con el árbol de archivos:

```
📁 mi-proyecto
  📁 src
    📁 components
      📄 Button.tsx
      📄 Input.tsx
    📁 pages
      📄 index.tsx
      📄 about.tsx
  📄 package.json
  📄 README.md
```

Haz clic en cualquier archivo para verlo sin recargar la página.

## Casos de uso para devs

**Code review de PRs**: al revisar un PR grande, navega el árbol de archivos afectados sin perder el contexto de qué cambió.

**Explorar proyectos open source**: en lugar de clonar para ver la estructura, usa Octotree para entender la arquitectura antes de contribuir.

**Repositorios monorepo**: fundamental para repos con muchas carpetas — ver la estructura completa de un monorepo de un vistazo.

## Atajos de teclado

| Atajo | Acción |
|-------|--------|
| `Ctrl+Shift+S` | Abrir/cerrar Octotree |
| `/` | Buscar en el árbol |
| `↑↓` | Navegar archivos |
| `Enter` | Abrir archivo |

## Versión gratuita vs Pro

La versión gratuita funciona perfectamente para repositorios públicos. La versión Pro añade:
- Repositorios privados (con token de GitHub)
- Múltiples columnas
- Marcadores de archivos

Para la mayoría de los casos de uso la versión gratuita es suficiente.
