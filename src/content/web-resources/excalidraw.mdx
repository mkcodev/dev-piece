## Diagramas técnicos rápidos con estilo boceto

Excalidraw es una pizarra virtual para hacer diagramas con estilo de dibujo a mano alzada. Sin registro, sin instalación, abre el navegador y dibuja. El resultado tiene un aspecto intencional de boceto que funciona perfectamente para comunicar ideas en revisiones de código, diseño de sistemas o propuestas de arquitectura.

## Cuándo usar Excalidraw

- **Diseño de arquitectura rápido**: cajas, flechas, bases de datos, servicios
- **Diagramas de flujo**: cuando Mermaid es demasiado rígido
- **Wireframes de UI**: pantallas y componentes a gran escala
- **Explicar algo a un compañero**: compartir un diagrama en segundos
- **En una PR**: adjuntar diagramas que explican el cambio

## Flujo de trabajo típico

1. Ve a **excalidraw.com** (sin registro necesario)
2. Dibuja con formas: rectángulos, flechas, texto, diamantes, elipses
3. Añade color, grosor de línea y estilos de relleno
4. `Ctrl+S` para guardar como `.excalidraw` (JSON)
5. `Share` → Link para colaboración en tiempo real
6. Exportar como PNG o SVG para documentación

## Atajos de teclado

| Tecla | Herramienta |
|-------|-------------|
| `R` | Rectángulo |
| `E` | Elipse |
| `A` | Flecha |
| `T` | Texto |
| `L` | Línea |
| `D` | Diamante (decisión) |
| `H` | Hand (mover) |
| `1` | Seleccionar |
| `Ctrl+G` | Agrupar selección |
| `Ctrl+Z` | Deshacer |

## Integración con VS Code

La extensión **Excalidraw** para VS Code abre archivos `.excalidraw` directamente en el editor:

```
ext install pomdtr.excalidraw-editor
```

Los diagramas pueden vivir en el repositorio como archivos `.excalidraw` versionados en Git.

## Librería de elementos técnicos

Excalidraw tiene una librería con iconos de AWS, GCP, Azure, Kubernetes, bases de datos, logos de tecnologías... perfectos para diagramas de arquitectura profesionales.

`+` → Library → Buscar "AWS Architecture" o "Database Icons".
