## ¿Qué es MDN Web Docs?

MDN (Mozilla Developer Network) Web Docs es la documentación de referencia más completa y fiable para tecnologías web. Cada atributo HTML, propiedad CSS, método JavaScript, y API del navegador está documentado con ejemplos interactivos, tablas de compatibilidad y guías detalladas.

Es el primer sitio al que cualquier desarrollador web debería acudir antes que Stack Overflow o foros.

## Lo que encontrarás

```
HTML
  ├── Todos los elementos y atributos
  ├── Guías de accesibilidad
  └── Formularios, multimedia, semántica

CSS
  ├── Todas las propiedades con ejemplos en vivo
  ├── Guías: Flexbox, Grid, Animaciones
  └── Funciones, at-rules, selectores

JavaScript
  ├── Referencia completa de objetos built-in
  ├── Guías por nivel: básico → avanzado
  └── Web APIs: Fetch, DOM, WebSockets, Canvas...

Web APIs
  ├── Fetch API, Web Storage, Geolocation
  ├── WebRTC, Web Workers, Service Workers
  └── View Transitions, Web Components...
```

## Trucos de búsqueda

```bash
# Añade "mdn" a cualquier búsqueda en Google
"css grid mdn"
"array map mdn"
"fetch api mdn"

# O busca directamente en la URL
https://developer.mozilla.org/es/search?q=grid
```

## Modo interactivo

Muchos ejemplos de código en MDN tienen un playground integrado que permite editar y ver los resultados sin salir de la documentación. Perfecto para experimentar con propiedades CSS o APIs JS.

## En español

MDN tiene una excelente traducción al español en `developer.mozilla.org/es/`. Si prefieres leer en inglés, la versión en inglés siempre está más actualizada.
