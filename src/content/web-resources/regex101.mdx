## ¿Qué es regex101?

regex101 es la herramienta de referencia para construir y debuggear expresiones regulares. Tiene soporte para múltiples sabores de regex (JavaScript, Python, PHP, Golang, Java) y proporciona en tiempo real:

- Qué coincide y qué no con colores
- Explicación de cada token del patrón
- Desglose del tiempo de ejecución
- Detección de backtracking catastrófico

## Funcionalidades

- **Flavor selector** — JavaScript, Python, PHP, Golang, Java, POSIX
- **Match information** — Muestra todos los grupos de captura
- **Code generator** — Genera el código en tu lenguaje favorito
- **Regex debugger** — Paso a paso de cómo el motor evalúa el patrón
- **Library** — Guarda y comparte tus regex con permalink

## Casos de uso comunes

```
Validar emails:       /^[\w.-]+@[\w.-]+\.[a-z]{2,}$/i
Extraer URLs:         /(https?:\/\/[^\s]+)/g
Parsear fechas:       /(\d{4})-(\d{2})-(\d{2})/
Limpiar espacios:     /\s+/g  →  ' '.trim()
Validar IPv4:         /^(\d{1,3}\.){3}\d{1,3}$/
```
