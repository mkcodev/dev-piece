## ¿Qué es DevDocs?

DevDocs es una web app que agrega la documentación oficial de más de 200 tecnologías en una sola interfaz con búsqueda instantánea. Puedes activar solo las docs que usas (React, Node.js, Python, etc.) y tener todo accesible desde un único lugar.

Lo mejor: **funciona offline**. Descarga las docs al navegador y las tienes disponibles sin internet.

## Tecnologías incluidas

```
Frontend:     HTML, CSS, JavaScript, TypeScript
Frameworks:   React, Vue, Angular, Svelte, Astro
Backend:      Node.js, Express, Django, FastAPI, Rails
Lenguajes:    Python, Rust, Go, Ruby, PHP, Java
Bases de datos: PostgreSQL, MySQL, MongoDB, Redis
DevOps:       Docker, Kubernetes, Nginx
Y muchas más...
```

## Cómo configurarlo

1. Entra a [devdocs.io](https://devdocs.io)
2. Haz clic en **"Preferences"** o la rueda de ajustes
3. Activa solo las tecnologías que usas actualmente
4. Haz clic en **"Install"** en cada doc para descarga offline
5. Usa `Cmd/Ctrl + K` para buscar al instante

## Atajos de teclado

```
/           → Abrir búsqueda
Tab         → Navegar resultados
Escape      → Cerrar búsqueda
Alt + G     → Buscar en Google la página actual
Alt + S     → Toggle sidebar
```

## Integración con Dash / Zeal

DevDocs está diseñado para web, pero si prefieres una app nativa:
- **Dash** (macOS) — La alternativa nativa premium
- **Zeal** (Windows/Linux) — Alternativa gratuita a Dash
- Ambas usan los mismos docsets que DevDocs
