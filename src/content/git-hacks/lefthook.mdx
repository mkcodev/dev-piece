## Hooks rápidos y en paralelo

Lefthook es un único binario en Go que lee un `lefthook.yml` y ejecuta los comandos de cada hook. A diferencia de Husky, no depende de Node, así que sirve igual para un monorepo JS que para un proyecto en Go, Python o Rust.

## Instalar en un repo

```bash
lefthook install   # Escribe los hooks en .git/hooks
```

## lefthook.yml de ejemplo

```yaml
pre-commit:
  parallel: true
  commands:
    lint:
      glob: "*.{js,ts,tsx}"
      run: npx eslint --fix {staged_files}
      stage_fixed: true
    format:
      glob: "*.{js,ts,tsx,css,md,json}"
      run: npx prettier --write {staged_files}
      stage_fixed: true
    types:
      run: npx tsc --noEmit

commit-msg:
  commands:
    conventional:
      run: npx commitlint --edit {1}

pre-push:
  commands:
    test:
      run: pnpm test
```

- `{staged_files}` se sustituye solo por los ficheros en stage que encajan con `glob`.
- `stage_fixed: true` vuelve a añadir al commit lo que el linter haya arreglado.

## Comandos útiles

```bash
lefthook run pre-commit       # Probar un hook sin hacer commit
LEFTHOOK=0 git commit -m "wip"  # Saltarse los hooks una vez
```

Cada desarrollador puede tener overrides locales en `lefthook-local.yml` (añádelo al `.gitignore`).
