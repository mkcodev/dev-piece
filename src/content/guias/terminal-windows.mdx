## La terminal de Windows por defecto es suficiente… ¿o no?

PowerShell 7 y Windows Terminal son perfectamente usables. Pero "usable" no es lo mismo que "productivo". Con el setup de esta guía vas a tener una terminal que:

- Se abre instantáneamente (Ghostty/WezTerm)
- Muestra información útil en el prompt sin configurar nada (Starship)
- Te deja buscar archivos y comandos de forma interactiva (fzf)
- Recuerda los directorios que más usas (zoxide)

---

## Paso 1: Instala tu emulador de terminal

### Ghostty (recomendado para empezar)

Ghostty es nuevo, rápido y con buenas configuraciones por defecto. Perfecto si quieres algo que funcione bien sin configurar demasiado.

```powershell
winget install ghostty
```

La configuración básica va en `%APPDATA%\ghostty\config`:

```ini
font-family = JetBrains Mono
font-size = 14
theme = catppuccin-frappe
window-decoration = false
```

### WezTerm (si quieres más control)

WezTerm es altamente configurable vía Lua. Más potente, con algo más de curva de aprendizaje.

```powershell
winget install wez.wezterm
```

## Paso 2: Configura el perfil de PowerShell

El perfil de PowerShell es un script que se ejecuta cada vez que abres una sesión. Es el equivalente al `.bashrc` o `.zshrc`.

Primero, verifica si ya existe:

```powershell
Test-Path $PROFILE
```

Si devuelve `False`, créalo:

```powershell
New-Item -Path $PROFILE -Type File -Force
```

Ábrelo para editarlo:

```powershell
notepad $PROFILE
```

Configuración base recomendada:

```powershell
# Aliases útiles
Set-Alias -Name ls   -Value eza   -Option AllScope
Set-Alias -Name cat  -Value bat   -Option AllScope
Set-Alias -Name grep -Value rg    -Option AllScope
Set-Alias -Name top  -Value btop  -Option AllScope

# Función para ir al directorio del proyecto rápido
function proj { Set-Location "C:\Users\$env:USERNAME\Projects" }

# Historial más inteligente
Set-PSReadLineOption -HistorySearchCursorMovesToEnd
Set-PSReadLineKeyHandler -Key UpArrow   -Function HistorySearchBackward
Set-PSReadLineKeyHandler -Key DownArrow -Function HistorySearchForward

# Predicciones inline (estilo fish)
Set-PSReadLineOption -PredictionSource History
Set-PSReadLineOption -PredictionViewStyle ListView
```

## Paso 3: Instala Starship

Starship es un prompt cross-shell escrito en Rust. Se instala una vez y funciona en PowerShell, Bash, Zsh, Fish...

```powershell
winget install Starship.Starship
```

Añade al final de tu `$PROFILE`:

```powershell
Invoke-Expression (&starship init powershell)
```

Crea el archivo de configuración de Starship en `~\.config\starship.toml`:

```toml
# Preset limpio y funcional
format = """
$directory$git_branch$git_status$nodejs$python$rust$cmd_duration$line_break$character"""

[character]
success_symbol = "[❯](bold green)"
error_symbol   = "[❯](bold red)"

[git_branch]
symbol = " "
style  = "bold mauve"

[git_status]
style = "bold red"

[directory]
style        = "bold blue"
truncate_to_repo = true
```

## Paso 4: fzf + zoxide

### fzf — fuzzy finder interactivo

fzf te permite buscar cualquier lista de forma interactiva. Integrado con PowerShell, `Ctrl+R` abre el historial de comandos con búsqueda difusa.

```powershell
winget install junegunn.fzf
```

Integración en `$PROFILE`:

```powershell
# Historial con fzf (Ctrl+R)
function _fzf_history {
    $selected = Get-Content (Get-PSReadLineOption).HistorySavePath |
        Select-Object -Unique |
        fzf --tac --no-sort --height 40%
    if ($selected) {
        [Microsoft.PowerShell.PSConsoleReadLine]::RevertLine()
        [Microsoft.PowerShell.PSConsoleReadLine]::Insert($selected)
    }
}
Set-PSReadLineKeyHandler -Chord Ctrl+r -ScriptBlock { _fzf_history }
```

### zoxide — cd inteligente

zoxide aprende los directorios que más visitas. Después de un tiempo de uso, `z pro` puede llevarte directamente a `C:\Users\tú\Projects\mi-proyecto`.

```powershell
winget install ajeetdsouza.zoxide
```

Añade a `$PROFILE`:

```powershell
Invoke-Expression (& { (zoxide init powershell | Out-String) })
```

Uso básico:

```powershell
z projects    # salta a tu carpeta de proyectos
z doc         # salta a Documentos
zi            # modo interactivo con fzf para elegir directorio
```
