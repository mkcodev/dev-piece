## Gemini en la terminal

Gemini CLI es un agente que lee y edita ficheros, ejecuta comandos, busca en la web y se conecta a servidores MCP. Su punto fuerte es la ventana de contexto muy grande de los modelos Gemini, útil para preguntar sobre repos enteros, y que con una cuenta de Google personal tiene un nivel gratuito.

## Primeros pasos

```bash
gemini                       # Sesión interactiva (pide login la primera vez)
gemini -p "resume los cambios del último commit"   # Modo no interactivo
```

## Referenciar ficheros y comandos

```
@src/lib/utils.ts explica esta función
@docs/ resume esta carpeta
!git status                  → ejecuta un comando de shell
/tools                       → herramientas disponibles
/mcp                         → servidores MCP conectados
/memory show                 → contexto cargado desde GEMINI.md
```

## GEMINI.md

Como `CLAUDE.md` o `AGENTS.md`: un fichero `GEMINI.md` en el proyecto (o en `~/.gemini/`) con instrucciones persistentes que el agente carga en cada sesión.

## Servidores MCP

```json
// ~/.gemini/settings.json
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}
```

## Sandbox

`gemini --sandbox` ejecuta las herramientas dentro de un contenedor (Docker o Podman), útil cuando dejas que el agente lance comandos sin supervisión.
