## ¿Qué es javascript.info?

javascript.info es el recurso más recomendado para aprender JavaScript moderno, independientemente de tu nivel. Cubre ES6+, DOM, eventos, AJAX, y conceptos avanzados como closures, prototypes, async/await y módulos. Todo con explicaciones claras, ejemplos prácticos y ejercicios con soluciones.

Es completamente gratuito, está disponible en más de 20 idiomas y se actualiza constantemente para reflejar el estándar más reciente del lenguaje.

## Estructura del tutorial

```
Parte 1 — El lenguaje JavaScript
  ├── Fundamentos: variables, tipos, operadores
  ├── Estructuras de datos: arrays, objetos, Map, Set
  ├── Funciones avanzadas: closures, recursión, decoradores
  ├── Prototypes y clases
  └── Promesas, async/await, generators

Parte 2 — JavaScript en el navegador
  ├── DOM: selección, modificación, creación de elementos
  ├── Eventos: bubbling, delegation, custom events
  ├── Formularios y validación
  ├── Fetch API y XMLHttpRequest
  └── Almacenamiento: localStorage, sessionStorage, cookies

Parte 3 — Temas adicionales
  ├── Web Components
  ├── Regular Expressions
  └── Animaciones con CSS y JS
```

## Por qué es la mejor referencia

- **Ejercicios al final de cada capítulo** con soluciones detalladas
- **Explicaciones de "bajo nivel"** para entender por qué funciona así, no solo cómo
- **Estilo de código limpio** y actualizado a ES2023+
- **Tareas de código** integradas en el navegador sin necesidad de setup
