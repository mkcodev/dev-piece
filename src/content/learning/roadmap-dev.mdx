## ¿Qué es roadmap.sh?

roadmap.sh es la plataforma de referencia para planificar tu aprendizaje como desarrollador. Creada por Kamran Ahmed y mantenida por miles de colaboradores, ofrece roadmaps visuales e interactivos para más de 20 tecnologías y roles: frontend, backend, DevOps, React, Node.js, Python, y muchos más.

Cada nodo del roadmap enlaza directamente a recursos de aprendizaje curados: documentación oficial, artículos, vídeos y cursos.

## Roadmaps más populares

- **Frontend Developer** — HTML → CSS → JavaScript → React/Vue/Angular
- **Backend Developer** — Node.js / Python / Go → Bases de datos → APIs → Deploy
- **DevOps Engineer** — Linux → Redes → CI/CD → Kubernetes → Cloud
- **Full Stack** — Combina frontend y backend con buenas prácticas

## Cómo usarlo

1. Entra a [roadmap.sh](https://roadmap.sh) y elige tu rol objetivo
2. Marca los temas que ya dominas con el check verde
3. Sigue los enlaces de cada nodo para aprender el tema en profundidad
4. Comparte tu progreso con un enlace público

## Pro Tips

**Crea tu cuenta gratuita** para guardar tu progreso y hacer seguimiento de los temas que vas completando. Puedes generar un enlace público y añadirlo a tu portfolio o CV para demostrar tu plan de aprendizaje estructurado.

**No intentes aprenderlo todo**: usa el roadmap para identificar las áreas más importantes para tu rol actual y prioriza. La profundidad supera a la amplitud.
