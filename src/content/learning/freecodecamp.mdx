## Aprender haciendo, gratis

freeCodeCamp es una organización sin ánimo de lucro con un currículo interactivo en el navegador: lees una explicación corta, escribes código y los tests te dicen si está bien. Cada bloque termina con proyectos que tienes que construir tú para obtener la certificación.

## Certificaciones

```
Diseño web responsive
Algoritmos y estructuras de datos en JavaScript
Bibliotecas de front-end (React, Redux, Sass)
Visualización de datos (D3)
APIs y microservicios back-end (Node, Express, MongoDB)
Python, análisis de datos y machine learning
Seguridad de la información y QA
```

El temario se actualiza a menudo; la lista completa está en la web.

## Más allá del currículo

- **Canal de YouTube en español:** cursos completos de varias horas sobre Python, JavaScript, React, SQL y más.
- **Noticias y guías:** miles de artículos técnicos escritos por la comunidad.
- **Foro:** si te atascas en un ejercicio, alguien ya preguntó lo mismo.

## Consejo

Combínalo con proyectos propios. Las certificaciones demuestran constancia, pero lo que más pesa en un portfolio es algo que construiste sin una guía paso a paso. The Odin Project es un buen complemento para ese salto.
