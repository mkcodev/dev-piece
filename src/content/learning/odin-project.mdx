## ¿Qué es The Odin Project?

The Odin Project (TOP) es uno de los currículos de desarrollo web más completos y respetados de la comunidad open source. No solo te enseña a seguir tutoriales: te hace construir proyectos reales desde el primer día, con el objetivo de prepararte para el mercado laboral.

Es completamente gratuito, mantenido por voluntarios y tiene una comunidad activa en Discord con decenas de miles de estudiantes.

## Rutas de aprendizaje

```
Fundamentos (Shared)
  └── Cómo funciona la web, Git, HTML/CSS básico, JavaScript

Full Stack JavaScript
  ├── HTML/CSS avanzado, Flexbox, Grid
  ├── JavaScript avanzado, ES6+
  ├── React
  ├── Node.js + Express
  └── Bases de datos relacionales (PostgreSQL)

Full Stack Ruby on Rails
  ├── Ruby desde cero
  ├── Ruby on Rails
  └── Bases de datos con ActiveRecord
```

## Filosofía del proyecto

TOP aplica el método **"aprender haciendo"**:

1. Lee una introducción conceptual
2. Estudia los recursos enlazados (MDN, libros, videos)
3. **Construye el proyecto** que integra todo lo aprendido
4. Comparte tu solución en GitHub

## Proyectos del currículo

Algunos proyectos que construirás:
- Calculadora en HTML/CSS/JS
- Librería de libros con LocalStorage
- Tablero de Etch-a-Sketch con canvas
- Weather app con API fetch
- Todo list con React
- Blog completo con Node.js + Express + PostgreSQL

## Consejo

Completa los proyectos aunque sean imperfectos. El proceso de resolución es más valioso que el resultado. La comunidad de Discord es muy activa para resolver dudas.
