## Un Postman ligero en una pestaña

Abres hoppscotch.io y ya puedes lanzar peticiones: sin descargas ni registro. Es rápido, tiene buen modo oscuro y cubre bastante más que REST.

## Protocolos

```
REST        → métodos, cabeceras, query params, body JSON/form/multipart
GraphQL     → explorador del schema con autocompletado
Realtime    → WebSocket, Server-Sent Events, Socket.IO y MQTT
```

## Funciones clave

- **Colecciones y entornos:** variables con `<<baseUrl>>` y entornos por proyecto.
- **Scripts pre-request y tests:** en JavaScript, para encadenar tokens o validar respuestas.
- **Generar código:** convierte cualquier petición a curl, fetch, axios, Python y muchos más.
- **Importar:** colecciones de Postman, Insomnia y OpenAPI.

## CORS y localhost

Desde el navegador, algunas peticiones fallan por CORS o porque apuntan a `localhost`. Para eso existen la extensión de navegador de Hoppscotch, el agente de escritorio (Hoppscotch Agent) o directamente la app de escritorio.

## Autoalojado

Para equipos que no quieren datos fuera: Hoppscotch Community Edition se despliega con Docker y añade espacios de trabajo compartidos y usuarios.

## CLI para CI

```bash
npm install -g @hoppscotch/cli
hopp test coleccion.json -e entorno.json
```
