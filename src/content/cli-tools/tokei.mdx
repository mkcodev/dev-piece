## ¿Cuánto código hay aquí?

tokei recorre un proyecto, respeta `.gitignore` y te da una tabla por lenguaje: ficheros, líneas totales, código, comentarios y blancos. Reconoce más de 200 lenguajes y es lo bastante rápido para repos enormes.

## Uso

```bash
tokei                      # Proyecto actual
tokei src/                 # Solo una carpeta
tokei --exclude "*.min.js" --exclude dist
tokei --sort code          # Ordenar por líneas de código
tokei --files              # Desglose por fichero
tokei --types TypeScript,Rust
```

## Salida para scripts

```bash
tokei --output json | jq '.TypeScript.code'
```

## Casos de uso

- Hacerte una idea del tamaño de un repo antes de contribuir.
- Ver la proporción de tests frente a código.
- Incluir estadísticas en un README o en un informe.
