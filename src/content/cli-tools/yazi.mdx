## ¿Qué es Yazi?

Yazi es un file manager de terminal (TUI) escrito en Rust que destaca por su arquitectura completamente asíncrona. A diferencia de `ranger` (Python), `lf` (Go) o `nnn` (C), Yazi renderiza previews de archivos sin bloquear la interfaz gracias a su diseño basado en tareas paralelas.

Sus capacidades de preview son excepcionales:
- **Imágenes** inline (protocolo Kitty, Sixel, iTerm2, Überzug++)
- **Videos** con miniaturas via ffmpegthumbnailer
- **PDFs** con página previa
- **Archivos de código** con resaltado via bat o chroma
- **Archivos comprimidos** (zip, tar.gz, etc.) mostrando contenidos
- **Office documents** con libreoffice

## Archivos de configuración

Yazi usa tres archivos de configuración en `~/.config/yazi/`:

```
~/.config/yazi/
├── yazi.toml      # Configuración principal
├── keymap.toml    # Atajos de teclado
├── theme.toml     # Colores y estilos
└── plugins/       # Plugins Lua
```

## Shell wrapper: ya() para cambiar de directorio al salir

Yazi no puede cambiar el directorio de la shell padre directamente. Esta función wrapper lo soluciona:

```bash
# ~/.bashrc o ~/.zshrc
function ya() {
  local tmp cwd
  tmp="$(mktemp -t "yazi-cwd.XXXXX")"
  yazi "$@" --cwd-file="$tmp"
  if cwd="$(cat -- "$tmp")" && [ -n "$cwd" ] && [ "$cwd" != "$PWD" ]; then
    builtin cd -- "$cwd"
  fi
  rm -f -- "$tmp"
}
```

```powershell
# PowerShell ($PROFILE)
function ya {
  $tmp = [System.IO.Path]::GetTempFileName()
  yazi $args --cwd-file="$tmp"
  $cwd = Get-Content -Path $tmp -ErrorAction SilentlyContinue
  if (-not [String]::IsNullOrEmpty($cwd) -and $cwd -ne $PWD.Path) {
    Set-Location -LiteralPath $cwd
  }
  Remove-Item -Path $tmp -ErrorAction SilentlyContinue
}
```

Ahora `ya` abre Yazi y al salir con `q`, la terminal cambia al último directorio visitado.

## Pro Tips

**Preview de imágenes:** Para imágenes inline necesitas un terminal compatible (Kitty, WezTerm, iTerm2) y tener instalado `ueberzugpp` para el resto. En macOS con iTerm2 funciona out of the box.

**Plugin de git:** Instala el plugin `git.yazi` para ver el estado de git en cada archivo directamente en el panel:

```bash
ya pack -a yazi-rs/plugins:git
```

**Búsqueda recursiva:** Presiona `s` para usar fd como búsqueda de nombres, o `S` para usar ripgrep y buscar en el contenido de los archivos.
