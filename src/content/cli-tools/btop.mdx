## ¿Qué es btop++?

btop++ es el monitor de recursos del sistema más bonito y completo de la terminal. Creado por Aristocratos en C++, muestra en tiempo real el estado de CPU, memoria RAM, swap, discos, red y GPU en una interfaz TUI completamente interactiva.

Es el sucesor espiritual de `htop` y `bpytop` (su predecesor en Python), pero mucho más rápido y con más funcionalidades. La diferencia visual con `top` o `htop` es abismal: btop usa bloques de caracteres para crear gráficas de barras y líneas fluidas en la terminal.

## Lo que muestra btop

- **CPU**: porcentaje por núcleo, frecuencia, temperatura, gráfica histórica
- **Memoria**: RAM, swap, buffers, caché con gráfica
- **Procesos**: lista interactiva con filtrado, árbol de procesos, información detallada
- **Red**: velocidad de upload/download por interfaz con gráfica en tiempo real
- **Disco**: I/O por dispositivo, espacio utilizado
- **GPU** (con soporte opcional): temperatura, uso de VRAM, procesos en GPU

## Atajos de teclado

```
# Navegación
q / Ctrl+C  → Salir
F1 / h      → Ayuda
←/→         → Cambiar sección activa
↑/↓         → Navegar en lista de procesos
Page Up/Down → Desplazarse más rápido

# Procesos
f           → Filtrar procesos (escribir para buscar)
T           → Árbol de procesos
r           → Ordenar procesos al revés
e           → Expandir proceso en árbol
k           → Enviar señal (kill, SIGTERM, etc.)
Enter       → Seleccionar proceso

# Vista
1           → CPU
2           → Memoria
3           → Red
4           → Discos
+/-         → Ajustar tamaño del panel
m           → Cambiar modo de memoria

# Configuración
Esc         → Abrir menú de opciones
p           → Seleccionar preset
t           → Cambiar tema
```

## Configuración: Catppuccin Frappé

El archivo de configuración está en `~/.config/btop/btop.conf`:

```ini
# ~/.config/btop/btop.conf

# Tema
color_theme = "catppuccin_frappe"

# Actualización cada 2 segundos
update_ms = 2000

# Mostrar segundos en el reloj
clock_format = "%H:%M:%S"

# Núcleos de CPU en una sola fila (false = columna)
cpu_single_graph = False

# Mostrar temperatura de CPU
check_temp = True
cpu_sensor = "Auto"

# Unidades de red (b = bits, B = bytes)
net_download = "10G"
net_upload = "10G"
net_auto = True
net_sync = True

# Procesos
proc_update_mult = 2
proc_sorting = "cpu lazy"
proc_reversed = False
proc_tree = False
proc_colors = True
proc_gradient = True
proc_per_core = True
proc_mem_bytes = True
proc_cpu_graphs = True
proc_info_smaps = False
proc_left = False

# Discos a monitorizar
disks_filter = ""
io_mode = False
io_graph_combined = False
io_graph_speeds = ""

# Mostrar GPU
gpu_mirror_graph = True
nvml_measure_pcie_speeds = True
gpu_warn_temp = 80
draw_clock = "%H:%M"

# Interfaz
rounded_corners = True
graph_symbol = "braille"  # braille | block | tty
background_update = True
custom_cpu_name = ""
shown_boxes = "cpu mem net proc"
presets = "cpu:1:default,proc:0:default cpu:0:default,mem:0:default,net:0:default cpu:0:block,net:0:tty"
```

## Monitoreo de GPU

Para monitorizar la GPU necesitas:

```bash
# NVIDIA: instalar nvidia-ml (incluido con drivers NVIDIA)
# La detección es automática en Linux y Windows

# AMD: compilar btop con soporte ROCm
# En Arch Linux:
sudo pacman -S btop-git  # Incluye soporte AMD GPU

# macOS: btop usa IOKit para información de GPU Apple Silicon
# No hay soporte para GPUs discretas en macOS
```

```ini
# Activar en btop.conf
shown_boxes = "cpu mem net proc gpu"
gpu_mirror_graph = True
```

## Comparación: btop vs htop vs top

| Característica | top | htop | btop++ |
|---|---|---|---|
| Gráficas | No | Básicas | Avanzadas |
| GPU | No | No | Si |
| Temas | No | Limitado | Completo |
| Red en tiempo real | No | No | Si |
| Árbol de procesos | No | Si | Si |
| Interfaz de ratón | No | Básica | Completa |
| Lenguaje | C | C | C++ |

## Pro Tips

**Presets de vista:** Presiona `p` para alternar entre presets predefinidos de disposición. Btop incluye 3 presets por defecto y puedes crear los tuyos en el archivo de configuración.

**Filtrar procesos:** Presiona `f` en el panel de procesos para filtrar por nombre en tiempo real. Muy útil para encontrar procesos que consumen recursos inesperadamente.

**Vista de árbol de procesos:** Presiona `T` para alternar entre vista plana y árbol jerárquico de procesos padre/hijo. Esencial para diagnosticar qué proceso inició un proceso hijo problemático.
