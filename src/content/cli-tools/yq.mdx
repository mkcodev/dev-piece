## jq para el mundo YAML

Media infraestructura moderna vive en YAML: Compose, Kubernetes, GitHub Actions, OpenAPI. yq (la versión de Mike Farah, en Go) usa una sintaxis muy parecida a la de jq y conserva comentarios y formato al editar.

## Leer

```bash
yq '.services.web.image' docker-compose.yml
yq '.jobs[].runs-on' .github/workflows/ci.yml
yq '.spec.template.spec.containers[0].image' deployment.yaml
```

## Editar en sitio

```bash
# Cambiar un valor
yq -i '.services.web.image = "nginx:1.27"' docker-compose.yml

# Usar una variable de entorno
TAG=v2 yq -i '.image.tag = strenv(TAG)' values.yaml

# Borrar una clave
yq -i 'del(.services.debug)' docker-compose.yml
```

## Convertir entre formatos

```bash
yq -o=json config.yaml          # YAML → JSON
yq -P config.json               # JSON → YAML legible
yq -p=toml -o=yaml Cargo.toml   # TOML → YAML
```

## Combinar ficheros

```bash
# Fusionar un override sobre una base
yq eval-all 'select(fileIndex == 0) * select(fileIndex == 1)' base.yml override.yml
```

**Ojo:** existe otro `yq` en Python (un envoltorio de jq) con sintaxis distinta. Los ejemplos de aquí son del de mikefarah, que es el que instalan winget, brew y scoop.
